# LumaViz v0.1 verification checklist

## Product flow

- BUILD edits the virtual venue and physical dimensions.
- PATCH maps fixtures to profiles, universes, and addresses.
- VISUALIZE is the main editable 3D environment.
- CAMERAS provides production-oriented preset views.
- CONNECT selects LumaRig Direct, Art-Net, sACN, or demo input.
- MONITOR is the clean visualization output.

## Control boundary

- LumaRig owns programming, playback, cues, songs, FX, and physical output.
- LumaViz owns venue geometry, fixture placement, patch interpretation, cameras, materials, and rendering.
- A LumaViz crash or disconnect must not interrupt LumaRig.

## Automated checks

- TypeScript production build
- Vitest suite
- Rust compile/check
- Native Art-Net parser tests
- Native sACN parser tests
- Camera preset tests
- Network-DMX patch mapping tests

## Packaging gate

After CI passes:

- Build universal macOS APP + DMG.
- Build Windows x64 NSIS EXE + MSI.
- Test launch on one Apple Silicon Mac and one Windows machine.
- Add signed updater publishing only after the release repository and signing secrets exist.
